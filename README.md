# 🏨 Waiting Room App (Flutter)

Application de gestion de salle d'attente / file d'attente locale développée avec Flutter & Dart.

## 📖 Documentation Complète
Une documentation détaillée expliquant l'interface utilisateur, la liste de tous les boutons/actions, la logique métier et une analyse ligne par ligne du code source est disponible dans [DOCUMENTATION.md](DOCUMENTATION.md).

## 🚀 Démarrage Rapide

```bash
# Récupérer les dépendances
flutter pub get

# Lancer l'application
flutter run

# Exécuter les tests
flutter test
```
